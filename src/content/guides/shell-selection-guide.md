In **Mortal Shell II**, a Shell is not just a costume. The official premise is that you possess Shells while recovering lost memories, and the developer has confirmed **eight playable Shells**. That makes selection a build decision, but there is not enough published data for a reliable tier list yet.

This guide turns the confirmed character descriptions into a practical way to choose a first test build. It does not invent health, damage, resolve, weapon, or ability numbers.

## The three confirmed starting signals

| Shell | What the official material calls it | How to test that role |
| --- | --- | --- |
| **Tiel** | The Acolyte | Look for a mobile, ability-led route that rewards reading enemy posture without assuming a specific skill or stat. |
| **Eredrim** | The Venerable | Test a deliberate, grounded approach and note how the Shell feels during committed attacks and defensive recoveries. |
| **Proxima** | The Broodseeker | Test whether the Shell's identity supports range, control, or a more unusual exploration rhythm once the retail kit is visible. |

The names are official. The suggested tests are planning prompts, not claims about hidden numbers. The gameplay reveal says each of the three **carves a different trail** through the interconnected world; it does not publish a complete ability list for them.

## Pick by the problem you want to solve

Use this decision order after you have seen the opening controls:

1. **Do you want more movement freedom?** Start with the Shell whose animations and recovery feel easiest to reposition from. The game is described as agile yet grounded, so movement comfort matters even without a stamina bar.
2. **Do you prefer commitment and timing?** Pick the Shell that makes heavy attacks readable to you. The combat description centres on shattering posture and striking critically, not on a universal damage race.
3. **Do you want a tactical experiment?** Try the Shell whose official identity sounds least like your normal action-game role, then record which sidearms and upgrades make it work.
4. **Are you unsure?** Do not spend the first session chasing a final build. Use the first dungeon as a controlled test of movement, posture pressure, sidearms, and upgrade availability.

## A ten-minute Shell test

For each Shell, write down the same five observations:

- how quickly you can recover from a missed attack;
- which action most reliably pressures enemy posture;
- whether a sidearm creates a safe critical window;
- which movement animation is easiest to read under pressure;
- whether the current weapon and upgrade choices support the role.

This keeps the comparison fair. A Shell can feel weak simply because its weapon is under-upgraded or because you are using the wrong posture tactic. The official combat wording confirms **no stamina restriction**, **posture shattering**, **critical strikes**, **powerful sidearms**, and **extensive upgrade options**, so all five observations belong in the same test.

## Do not import Mortal Shell I numbers

The first game is useful context for the studio's design language, but Harden, Resolve, Riposte values, Shell health, and weapon scaling from 2020 are not confirmed Mortal Shell II data. This site labels that material as prequel context for a reason. Do not use a first-game build chart as a sequel tier list.

## What to record at launch

When the full game releases, update your notebook with:

1. Shell acquisition point and whether switching requires a hub or a field interaction.
2. Confirmed stats, abilities, and upgrade paths.
3. Which sidearms interact with posture most reliably.
4. Any Shell-specific route, dungeon shortcut, or memory requirement.
5. Whether respec or weapon upgrades are limited by a resource.

Until those values are published or tested in the retail build, the safest recommendation is role-first selection: choose the Shell whose movement and posture loop you can read, then build around the weapon and sidearm that make that loop consistent.
