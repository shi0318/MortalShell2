The live Steam listing for **Mortal Shell II** has a compact but useful feature block. It currently lists **Single-player**, **Steam Achievements**, **Full Controller Support**, **DualSense Controller Support**, **Steam Cloud**, and **Family Sharing**. These are storefront features, not a substitute for a full launch-day settings guide, so this page separates what they confirm from what they do not.

## Confirmed on the Steam listing

| Steam category | What it safely tells you |
| --- | --- |
| **Single-player** | Steam currently markets the PC game as a single-player experience. |
| **Steam Achievements** | The Steam version has achievements; the public listing does not disclose their names or conditions. |
| **Full Controller Support** | A controller can be used throughout the Steam version. |
| **DualSense Controller Support** | DualSense support is listed. Steam does not specify which adaptive-trigger, haptic, or wired/wireless behaviours are implemented. |
| **Steam Cloud** | Steam Cloud support is listed for the PC version. The listing does not explain save-slot count, conflict handling, or backup limits. |
| **Family Sharing** | The Steam listing marks the game as compatible with Family Sharing. |

## What this does not confirm

The same official listing does **not** announce co-op, PvP, multiplayer matchmaking, cross-play, or cross-save between PC and consoles. A Steam Cloud label is not cross-save: it describes the Steam version's cloud feature and says nothing about transfers to PlayStation 5 or Xbox Series X|S.

It also does not publish a complete control-remapping, accessibility, vibration, or graphics-options matrix. Do not treat an icon in the Steam feature block as proof of a specific setting until Cold Symmetry or Playstack documents it.

## A practical retail-build check

1. Use the official Steam page to confirm the feature tags in your own region before purchase.
2. If you plan to use a controller, check the final build's in-game prompt style and remapping options rather than assuming all DualSense features are present.
3. Enable Steam Cloud only after checking your local save path and available storage; a cloud feature reduces risk but is not a replacement for a backup policy.
4. Treat any claim about co-op, PvP, cross-play, or console-to-PC progression as unconfirmed until an official feature list names it.
