## The five map notes worth keeping

For every region or dungeon, write down the **entrance**, nearest rest point, first locked interaction, shortcut, and exit connection. These notes answer the questions players actually ask after a death: where was the entrance, which branch was safe, and which unopened path should be revisited after a new upgrade?

Use four labels: **open**, **tested**, **locked** and **unknown**. “Unknown” is useful data. It tells you not to turn a visual landmark into a guessed key, boss or item location.

## How to explore 80-plus dungeons without losing the route

Make a first pass for survival, a second pass for connections and a third pass for upgrades. On the first pass, locate the exit and retreat route. On the second, test whether a Shell, sidearm or weapon changes the safe line. On the third, collect the branches you deliberately left behind.

The compact world rewards revisits, but a revisit is only efficient if you log the reason: missing tool, uncertain door, unsafe enemy group, or a shortcut not yet tested. A screenshot of a landmark is often more useful than a map pin with no explanation.

## Map claims that need a current-build check

The retail information confirms the world structure and dungeon count, not a complete reward table, exact region order, or every coordinate. The [dungeon exploration guide](/dungeon-exploration-guide/) explains the same network from the combat side. Keep map updates dated when a patch changes a door, reward or route.
