Seeking the Past failing to unlock was listed next to the Egon's Stone dungeon bug. Same hotfix. If the achievement is dark and you already did the in-game step, install that pass before you replay the memory.

## If it is still dark after the patch

- Confirm the dungeon tied to the step actually loaded. A failed Egon's Stone load can look like you finished a room you never entered.
- Reload the checkpoint after the patch, then repeat the last interaction. A pop that failed on the broken build does not always backfill.
- Do not start a new file as the first fix. The notes describe a trophy bug, not a missable flag.

The full [achievement route](/mortal-shell-2-achievements/) is the list. This page is the one name people are searching because it stayed dark after a clean play.
