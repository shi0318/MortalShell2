A recent file at 18 hours names the fall, not the boss: a small crack on a ledge, a slide, and 25 minutes of Gloom gone. That is not Harden failing. That is the collision. The dense map people praise is the same map that hides those edges.

Do not diagnose it as a dodge that “went through the floor.” Test the lip before you commit a pouch. If you already fell, the pile on the ground is only yours if Egon's Stone is not deleting open-world Gloom. Patch that first. See the [Egon's Stone hotfix](/mortal-shell-2-egons-stone-hotfix/).

## How to keep the pouch

- Slow down on ledges that show a hairline gap. If it looks like you can slide, you can.
- Drop a beacon or a known return before a long traverse. The fall is expensive because the runback is long, not because the crack is rare.
- Harden still works. It does not glue you to a broken lip. See [Harden still works](/mortal-shell-2-harden-still-works/).
- Fast travel does not refund a fall you already took. The [map and fast travel page](/mortal-shell-2-map-fast-travel/) is the corridor complaint, not this one.

The Very Positive score is still the first-half loop. This page is the 18-hour file that almost left because of a crack, not because of a boss.
