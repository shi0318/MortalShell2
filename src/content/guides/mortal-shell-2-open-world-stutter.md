Open-world traversal stutter is one of the most common **Mortal Shell 2** PC complaints in recent Steam reviews, alongside frame generation that seems broken. The game is still **Very Positive** overall (**7,812 / 9,444**), so this is a performance split, not a review collapse.

![Mortal Shell 2 world map](/images/mortalshell2-world-map-overview.webp)

## What reviewers describe

The stutter shows up while moving between regions, not only in boss arenas. That matches an open-world streaming problem more than a single-fight hitch. Frame generation is mentioned as unreliable rather than as a guaranteed boost.

Week 1 Update and Balance Patch 1 retuned bosses and weapons. They did not publish a full traversal-stutter changelog you can treat as a confirmed fix.

## What to try first

Use the retail PC settings page and the frame-generation fix page before rewriting config files. If the hitch is only outdoors, lower foliage and shadows before touching internal resolution.
