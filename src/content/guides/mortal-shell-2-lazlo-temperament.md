A post-launch hotfix names **Lazlo's Temperament** as an infinite perk glitch. The same pass unsticks **Proxima** if Biosampler never returns control. Those are two shells, one note. If Temperament never expires, or if the hook animation never ends, install that hotfix before you call the shell broken.

This page does not invent Lazlo's retail kit. Week 1 notes mention Lazlo in a softlock / Rekindle / armor-loop context. Temperament as an infinite loop is the hotfix line. Stats, a moveset, and a “best weapon for Lazlo” ranking are not published here.

## After it installs

- Re-enter Lazlo and fire the perk once. If it still loops, you are not on that hotfix.
- If the problem was Proxima's hook, see [Proxima Biosampler](/mortal-shell-2-proxima-broodseeker/). Do not mix the two animations.
- Egon's Stone dungeon loads are a different hotfix. See [Egon's Stone](/mortal-shell-2-egons-stone-hotfix/).

Very Positive at 8,331 of 10,043 is the first-half loop. This page is the shell perk that would not turn off.
