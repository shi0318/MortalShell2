**Mether's Severance** is Mortal Shell 2's respec item. It breaks your bond with the Shell you are currently using and **refunds every Glimpse** you spent on it. Because Glimpse does not respawn outside New Game Plus, it is the only way to fix a badly spent Shell tree.

![A cloaked Shell faces an armoured warrior in a misty forest](/images/ms2-hot-4.webp)

## Where to get it

| Detail | Value |
|---|---|
| Seller | **Merrick**, Marrow Keep |
| Tab | **Rare Findings** |
| Price | 5,000 coins each |
| Stock | Refreshes as you progress and beat main bosses – check again if the tab is empty |

## How to use it

1. Buy it from Merrick.
2. Make sure you are bonded to the Shell you want to reset – swap at a beacon first if needed.
3. Talk to **Zhirelle** and choose **Shell Severance**.
4. Confirm the prompt that names the Shell.
5. Spend the refunded Glimpse on any Shell at Zhirelle.

## Fixes you may have hit

| Hotfix | Fix |
|---|---|
| 14 September | Mether's Severance can now be used at the **Genessa trainer** |
| 24 September | Fixed a soft lock when cancelling Severance with a gamepad; Stray Genessa interactable after Severance |

If a guide told you to use it and nothing happened, you were on a build before these fixes.

## When it is worth 5,000 coins

- You spread Glimpse across three Shells and want one fully upgraded for a boss.
- You picked the wrong column of skills (for example, Genessa's Doubles column matters more than you thought).
- Before Malborn Offspring or Zmey, when a specific tier-4 skill (Tiel's Shadow Clone, Genessa's Stray Double) decides the fight.

Earn coins by selling the Unfound Path trade items (5,000 each) or the Marsh Pearl from Gorf (2,000).
