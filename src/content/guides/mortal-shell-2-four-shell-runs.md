People with four clears describe four builds and one game. The shell changes the weapon angle and the temperament perks. It does not change the corridor layout or the last boss's right to end a run.

## What a second shell is for

- A different punish. Proxima's hook-into-Lightning is not the same fight as a great weapon's harden-and-riposte.
- A respec, if the first tree was a guess. The Week 1 refund item is how you do that without a new file, but a new shell is still the cleaner test.
- Not a skip for the map. Fast travel complaints show up on every shell.

Lazlo's Temperament perk had an infinite loop that a hotfix closed. If a temperament build feels broken in a way that prints resources, patch before you call it a strategy. The [shells page](/shells/) is the roster. This page is the reason a second run is worth it: the verb stays, the tool does not.
