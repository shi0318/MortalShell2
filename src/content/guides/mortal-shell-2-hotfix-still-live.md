Steam's news feed for App 2584270 still leads with **Hotfix Live Now**. Older notes used the same title. That means the build can move without a new marketing name. Install the current download before you judge a ledge fall, a seal, or a last-boss item.

The October 13 note already added warnings on **Mether's Breath** so backing out of the second warning would not soft-lock. Treat that as a retest, not as proof every lock is gone.

## Retest order

1. Let Steam finish the current hotfix and restart.
2. Load the save that failed. Do not start a new game first.
3. Ledge falls: [ledge falls](/mortal-shell-2-ledge-falls/). Last-boss item: [last boss item](/mortal-shell-2-last-boss-item/). Seal names: **Vatra's Seal** from Harros after the Tar Golem, not a second spelling.

If the same step fails on the new download, report that build. A note titled Hotfix Live Now is not a changelog you can quote line by line from the title alone.
