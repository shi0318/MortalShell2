There is no published retail list that says every **Mortal Shell II** dungeon must be cleared in one fixed order. The game instead presents a compact interconnected world with more than 80 dungeons, Shells, weapons and upgrades away from the direct route.

## A progression order that does not pretend to be a walkthrough

1. Follow the nearest clear objective until you understand the local enemy rhythm.
2. Take one nearby side path and look for a Shell, weapon, upgrade or shortcut.
3. Return to the main route if the detour only costs healing and teaches nothing new.
4. Mark locked branches and revisit them after a confirmed progression change.
5. Before a Corrupted Gate, finish only the nearby tests that improve survival or route knowledge.

This order is deliberately problem-led. It prevents a player from spending an hour clearing a branch merely because a checklist placed it earlier.

## What counts as progress?

Progress can be a new Shell, weapon, sidearm, Tarstone, map fragment, memory, shortcut or a reliable answer to an enemy’s attack. The Steam achievement list separately tracks all Shells, all map fragments, all Tarstones and all Ova, so these are not interchangeable collection tasks.

## When to return

Return after a Shell changes your defensive timing, a sidearm fixes a range problem, or a weapon upgrade makes a known punish safer.
