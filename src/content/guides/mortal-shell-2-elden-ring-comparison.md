A typical recent Steam line for **Mortal Shell 2** is: open-world feel like Elden Ring, dungeon structure like Dark Souls 3. That is player language, not a developer slogan.

![Mortal Shell 2 map cover](/images/mortalshell2-world-map-cover.webp)

## Where the comparison holds

There is a connected overworld, named Beacons, optional Corrupted Gates, and separate dungeon spaces. Shells replace a single character build. Boss names were hidden in achievements until the Week 1 patch listed them.

## Where it breaks

There is no published jump-button sandbox of Elden Ring's size. Traversal stutter in the overworld is a PC complaint Elden Ring players will recognize, but it is not proof of the same engine.

Use the map and dungeon pages for this game's actual structure.
