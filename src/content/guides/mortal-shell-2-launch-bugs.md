## Sort the problem before looking for a fix

Use the symptom to choose a checklist:

- **Blurry image:** compare resolution, upscaling, and presentation settings with the [blurry graphics checklist](/mortal-shell-2-blurry-graphics-fix/).
- **Uneven frame pacing:** test Reflex and frame generation separately with the [stutter guide](/mortal-shell-2-reflex-stutter-fix/).
- **Frame generation not engaging:** use the [frame-generation guide](/mortal-shell-2-frame-generation-fix/).
- **Configuration experiments:** read the [Engine.ini safety guide](/mortal-shell-2-engine-ini-settings/) before editing files.

## Why a single review is not a patch note

Steam reviews capture hardware, drivers, settings, and individual routes. One player reports a bug that another does not see; both can be genuine. Do not turn a single review into a universal statement such as “the game is unplayable” or “this fix works for everyone.” Track the game version, GPU, resolution, and whether the report came from the Beta or retail build.

The official Steam PC requirements are Windows 10/11, 16 GB RAM, DirectX 12, an RTX 2060 SUPER or RX 6600-class GPU, and an SSD. Official patch notes should replace this snapshot when the developer publishes them.
