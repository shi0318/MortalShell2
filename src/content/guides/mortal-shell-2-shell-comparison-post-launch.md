**Mortal Shell II has eight playable Shells.** The useful question is not which one has a universal S-tier label; it is which Shell gives your current weapon, sidearm and parry habits enough room to work.

## What the released game confirms

The retail game tracks eight Shells, Shell Memories and bonding at the Shellkeeper. The Steam achievement list separates Shell progression from weapons: **Shell Seeker** requires every Shell, **Decked Out** requires maximum bonding for one Shell, and **Seeking the Past** requires every Shell Memory. Those objectives describe the progression structure without publishing a universal best Shell.

## A practical comparison method

Compare a Shell in the same dungeon, against the same enemy, with the same weapon and Tarstones. Write down whether the Shell helps with one of these jobs:

- surviving a mistake while learning an attack pattern;
- creating a safer parry or riposte window;
- supporting a ranged or sidearm-focused approach;
- making a long dungeon return route less punishing;
- unlocking a memory or bond that changes how you want to play.

Do not compare a Shell after changing three other variables. A new weapon, a different Tarstone and a new Shell at the same time cannot tell you which change helped.

## Which Shell should a new player use?

Start with the Shell whose defensive timing you can read consistently, then spend bonding progress only after you know the route is worth repeating. The game has no stamina bar for attacks or dodges, so the beginner decision is about spacing, guard timing and recovery rather than conserving a stamina meter.

The [Shell selection guide](/shell-selection-guide/) covers the broader decision. Use this page as the post-launch comparison checklist and record the Shell name, dungeon, weapon and patch version whenever you test a new setup.

## What this page does not claim

No official retail table establishes a universal Shell damage ranking, exact health values, or a single best Shell for every dungeon. A guide that supplies those numbers without a dated in-game test is presenting an estimate as fact. The honest answer is to choose a role, test it in a controlled route, and update the comparison when a patch changes a mechanic.
